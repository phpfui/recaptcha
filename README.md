# Google's reCAPTCHA PHP client library

### Notice: This is not an officially supported version of the Google Recaptcha package

This package was an updated version of the original Google package to support more modern PHP coding standards and versions of PHP and updated to GitHub Actions. Every effort has been made to not change logic or behavior other than conforming to modern PHP standards.

Google is now maintaining the [original recaptcha package](https://packagist.org/packages/google/recaptcha), so please use that going forward.
